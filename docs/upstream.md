# 上游固件

`firmware/xiaozhi` 是 [78/xiaozhi-esp32](https://github.com/78/xiaozhi-esp32) 的 git subtree（MIT）。不要直接修改该目录下的文件；升级请用下面的 subtree 命令。

- 上游仓库：https://github.com/78/xiaozhi-esp32
- 当前版本：v2.5.2

升级到其它 tag 时，在仓库根目录执行：

```bash
git subtree pull --prefix=firmware/xiaozhi https://github.com/78/xiaozhi-esp32 <tag> --squash
```
